# ApplyKit free resume sample

An original, editable one-page A4 resume template with a simple single-column structure.

[Download and preview the sample](https://invinsibledev.github.io/applykit-sample/)

The ZIP includes a blank DOCX, a fictional filled PDF example, short instructions and the sample license. Replace all placeholders and use only your own truthful experience. Examples are not real people or credentials.

The document was opened and rendered in LibreOffice on Linux. Microsoft Word and Google Docs were not independently tested. Check your final export and follow the employer's format instructions. No ATS or employment guarantees.

The [optional full pack](https://aleksi41.gumroad.com/l/applykit) adds two-page resumes, US Letter sizes, cover letters, an application tracker and guides. This repository contains only the free sample and preview page.
